# Links Manager Component

A Joomla component for building and managing hierarchical lists of links from the site administrator. Each link can point to an external URL, a downloadable document, a Joomla menu item, or an article — or act as an empty heading to group other links — and can be nested under a parent link, assigned a custom image, manually reordered, and published/unpublished, making it easy to build structured link directories, resource pages, or navigation trees anywhere on your site.

## ✅ Prerequisites

- Joomla 5.x (Not tested yet on Joomla 4 and Joomla 6)
- PHP 8.x
